أضف صفحة جديدة في الموقع باسم "عام الذكاء الاصطناعي" ضمن قسم Library، تعمل كمعرض صور مركزي لكل تفاعلات وتفعيلات الإدارة خلال عام الذكاء الاصطناعي ٢٠٢٦، مع عدّاد إجمالي للتفعيلات وإمكانية الرجوع لكل تفعيل بتفاصيله.

١) الواجهة (RTL عربي، نفس design system):

- Header علوي:
  • عنوان الصفحة "عام الذكاء الاصطناعي ٢٠٢٦".
  • شريط إحصائيات بصري (KPI cards): إجمالي التفعيلات، إجمالي الصور، عدد القنوات المستخدمة، آخر تحديث.
  • زر بارز "+ إضافة تفعيل جديد".

- منطقة الفلاتر:
  • فلتر بالشهر.
  • فلتر بنوع التفعيل (حملة/فعالية/ورشة/منشور/فيديو/تصميم/إنفوجرافيك).
  • فلتر بالقناة (إيميل/تواصل اجتماعي داخلي/شاشات/لقاء حضوري).
  • بحث نصي في عنوان ووصف التفعيل.

- المعرض (Gallery Grid):
  • شبكة بـ ٣ أعمدة على الشاشات الكبيرة، عمودين على المتوسطة، عمود واحد على الجوال.
  • كل بطاقة تعرض: الصورة المصغّرة، عنوان التفعيل، الشهر، نوع التفعيل (badge ملوّن).
  • بالنقر تفتح Lightbox بتفاصيل التفعيل الكاملة + تكبير الصور.

- نمطا عرض قابلان للتبديل: Grid View / Timeline View (محور زمني عبر شهور السنة).

٢) قاعدة البيانات (PostgreSQL):

- جدول ai_year_activations:
  id, title_ar, description_ar, activation_type, channel, target_audience, activation_date, month, created_by, created_at, updated_at, tags (array), status (مكتمل/قيد التنفيذ/مخطط).

- جدول ai_year_media:
  id, activation_id (FK), file_url, file_type (image/video), thumbnail_url, file_size, alt_text, sort_order, uploaded_at.

- جدول ai_year_metrics:
  id, activation_id (FK), reach_count, engagement_count, feedback_summary, notes.

٣) رفع الصور:

- يدعم رفع متعدد (drag & drop + ملف عادي).
- صيغ مدعومة: JPG, PNG, WEBP, MP4 (للفيديوهات القصيرة).
- حد ١٠MB لكل صورة، ٥٠MB للفيديو.
- توليد thumbnail تلقائي عند الرفع باستخدام Sharp library.
- تخزين الملفات في Replit Object Storage مع مسارات منظمة: /ai-year/{year}/{month}/{activation_id}/.
- ضغط الصور تلقائياً مع الحفاظ على الجودة.

٤) نموذج إضافة تفعيل جديد (Modal):

حقول الإدخال:
- عنوان التفعيل (مطلوب).
- وصف مختصر (٣–٥ أسطر).
- نوع التفعيل (قائمة منسدلة).
- القناة المستخدمة (متعدد الاختيار).
- الجمهور المستهدف.
- التاريخ.
- الوسوم/Tags لتسهيل البحث لاحقاً.
- منطقة رفع الصور والفيديوهات (متعدد).
- حقول اختيارية للمؤشرات: عدد الوصول، عدد التفاعل، ملاحظات.

زر "حفظ" يخزّن في الجداول الثلاثة دفعة واحدة.

٥) صفحة تفاصيل التفعيل (Lightbox/Modal):

- معرض صور قابل للتمرير (carousel) بكل وسائط التفعيل.
- بيانات التفعيل كاملة في عمود جانبي.
- المؤشرات (Reach/Engagement) في بطاقات صغيرة.
- أزرار: تعديل، حذف، تنزيل كل الصور كـ ZIP، نسخ رابط مشاركة داخلي.

٦) لوحة ملخص بصرية أعلى الصفحة (Dashboard Strip):

- Chart خطي: عدد التفعيلات شهرياً عبر السنة.
- Chart دائري: توزيع التفعيلات حسب النوع.
- Chart عمودي: التفعيلات حسب القناة.
- استخدم recharts بألوان متناسقة مع identity الموقع.

٧) ميزة "التقرير السنوي" التلقائي:

- زر "توليد تقرير سنوي" يصدّر تقرير Word منسّق يشمل:
  • مقدمة عن جهود الإدارة في عام الذكاء الاصطناعي.
  • الإحصائيات الإجمالية.
  • جدول بكل التفعيلات مرتّبة زمنياً.
  • أبرز الصور (تختار أعلى ٣ تفعيلات تفاعلاً).
  • ملحق بكل الصور بجودة عالية.

٨) Secrets وإعدادات Replit:

- تفعيل Replit Object Storage لتخزين الميديا.
- متغير AI_YEAR=2026 ليسهل تعديله مستقبلاً لسنوات قادمة.

٩) الأمان والصلاحيات:

- نفس نظام الدخول الحالي.
- صلاحية الحذف للمدير فقط (دور admin).
- نسخ احتياطية تلقائية أسبوعياً لقاعدة البيانات والملفات.

ابدأ بإنشاء الـ schema، ثم Object Storage، ثم واجهة المعرض، ثم نموذج الإضافة، ثم Lightbox، ثم Dashboard، ثم ميزة التقرير. اختبر برفع ٥ تفعيلات تجريبية بصور متنوعة.
