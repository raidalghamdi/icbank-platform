أضف صفحة جديدة في الموقع باسم "الأيام العالمية" ضمن قسم Library، تعمل كمحرك بحث ذكي لتجهيز التفعيل السريع للأيام العالمية بمصادر موثقة وأرشيف قابل للرجوع.

١) الواجهة (RTL عربي، نفس design system):
- شريط بحث رئيسي بارز: "اكتب اسم اليوم العالمي… مثل: اليوم العالمي للموارد البشرية".
- فلاتر سريعة: السنة، الفئة (صحة/تعليم/بيئة/موارد بشرية/تقنية/اجتماعي…).
- زر "بحث عميق" يفعّل البحث الكامل بالمصادر.
- زر جانبي "الأرشيف" يعرض السجلات المحفوظة سابقاً مع بحث داخلي.

٢) قاعدة البيانات (PostgreSQL):
- جدول international_days:
  id, day_name_ar, day_name_en, annual_date, category, official_organizer, history_summary, created_at, updated_at.
- جدول day_yearly_themes:
  id, day_id, year, theme_ar, theme_en, theme_source_url.
- جدول day_activations:
  id, day_id, year, entity_name, entity_type (حكومي/خاص/دولي), activation_type (تصميم/فيديو/حملة/فعالية/منشور), description, media_url, source_url, country.
- جدول sources:
  id, related_table, related_id, source_url, source_title, source_publisher, accessed_at.
- جدول search_history:
  id, query, day_id, searched_at, user_id.

٣) محرك البحث الذكي (Pipeline):
عند ضغط "بحث عميق" نفّذ الخطوات بالتوازي:
أ) تحقق أولاً من جدول international_days: إن وُجد اليوم، اعرض البيانات المحفوظة فوراً مع زر "تحديث ببحث جديد".
ب) إن لم يوجد، شغّل البحث:
   - استخدم Perplexity API (نموذج sonar-pro) للحصول على إجابة شاملة مع citations مدمجة. هذا النموذج الأفضل لأنه يُرجع مصادر فعلية لا يخترعها.
   - بالتوازي، شغّل web search عبر Anthropic API (claude-sonnet-4-5 مع web_search tool) للتحقق المتقاطع من المعلومات.

ج) البرومبت الموحد للنموذجين:
"ابحث عن "{day_name}" واستخرج بدقة:
1. التاريخ السنوي الثابت (يوم/شهر).
2. الجهة الراعية الرسمية دولياً (UN, WHO, إلخ).
3. شعار/ثيم هذا العام {current_year} مع رابط المصدر الرسمي.
4. ملخص تاريخي مختصر (٣ أسطر) عن نشأة اليوم.
5. أمثلة على تفعيلات سابقة من جهات سعودية وخليجية وعالمية (حكومية وخاصة) خلال آخر ٣ سنوات: اسم الجهة، نوع التفعيل (تصميم/فيديو/حملة/فعالية)، وصف موجز، رابط مباشر للمحتوى إن وُجد.
6. أفكار محتوى مقترحة قابلة للتطبيق في بيئة عمل حكومية سعودية.
أرجع النتيجة JSON منظم. كل معلومة لها حقل source_url إلزامي، ولا تذكر أي معلومة بدون مصدر."

د) ادمج نتائج النموذجين، احذف التكرار، ورتّب التفعيلات حسب: سعودية → خليجية → عربية → عالمية.

٤) عرض النتائج:
بطاقات منفصلة بترتيب:
- بطاقة "التعريف": الاسم، التاريخ، الجهة الراعية، ملخص تاريخي. مع أيقونة 🔗 لكل مصدر.
- بطاقة "شعار {السنة}": الثيم الرسمي + رابط المصدر.
- بطاقة "تفعيلات سابقة": grid يعرض كل تفعيل (شعار الجهة، نوعه، وصف، زر "افتح المصدر").
- بطاقة "أفكار مقترحة للتفعيل": قائمة قابلة للنسخ.
- بطاقة "المصادر": قائمة مرقمة بكل الروابط المستخدمة.

كل معلومة بدون مصدر يجب أن تظهر مع علامة ⚠️ "غير موثق - يحتاج تحقق".

٥) الحفظ التلقائي والأرشفة:
- بعد عرض النتائج، زر "حفظ في الأرشيف" يخزّن الكل في الجداول المذكورة.
- زر "تصدير كـ Word" يولد ملف منسّق جاهز للعرض على المدير.
- زر "تحديث البيانات" يعيد تشغيل البحث ويحدّث السجل مع الاحتفاظ بالنسخة السابقة في history.

٦) صفحة الأرشيف الداخلية:
- بحث نصي + فلترة بالسنة والفئة.
- بطاقة لكل يوم عالمي محفوظ، تفتح بنقرة على التفاصيل الكاملة.
- إمكانية المقارنة بين سنتين للثيمات السابقة.

٧) Secrets المطلوبة في Replit:
PERPLEXITY_API_KEY, ANTHROPIC_API_KEY.

٨) قيود وأمان:
- نفس نظام الدخول الحالي للموقع.
- حد ١٠ عمليات بحث عميق في الساعة لكل مستخدم لتجنب استهلاك API.
- caching لمدة ٧ أيام للنتائج المحفوظة قبل الحاجة لتحديث.

ابدأ بإنشاء الـ schema، ثم صفحة البحث وعرض النتائج، ثم ربط Perplexity + Anthropic، ثم صفحة الأرشيف، واختبر بـ"اليوم العالمي للموارد البشرية" و"اليوم العالمي للصحة النفسية".
