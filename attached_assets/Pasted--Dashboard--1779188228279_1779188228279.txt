أعد بناء الصفحة الرئيسية "الرئيسية" في موقع بنك التواصل الداخلي لتكون لوحة قيادة (Dashboard) جذابة تختصر كل خدمات الموقع وتسمح بالغوص لأي صفحة بنقرة واحدة.

١) المبدأ العام:
- الصفحة تعمل كـ Executive Cockpit: نظرة شاملة في شاشة واحدة دون تمرير طويل.
- كل قسم يعرض ملخصاً ذكياً + رابط مباشر للصفحة التفصيلية.
- تصميم RTL عربي فاخر، نفس design system للموقع، مع تركيز على المساحات البيضاء والتسلسل البصري.

٢) هيكل الصفحة من الأعلى للأسفل:

**أ) Hero Header:**
- ترحيب ديناميكي بالاسم: "أهلاً، أحمد 👋" مع التاريخ الهجري والميلادي.
- جملة سياقية ذكية حسب الوقت واليوم:
  • أيام الأحد–الأربعاء: "أسبوع منتج بانتظارك".
  • الخميس: "نهاية أسبوع موفقة".
  • أيام الإجازة: "نتمنى لك إجازة سعيدة".
- شريط KPI أفقي بأربع بطاقات صغيرة:
  • إجمالي المبادرات النشطة.
  • محتوى تم إنتاجه هذا الشهر.
  • تفعيلات عام الذكاء الاصطناعي.
  • أيام عالمية قادمة هذا الشهر.

**ب) قسم "خدماتنا الرئيسية" (Quick Access Grid):**
شبكة من ٤ بطاقات كبيرة بصرية متساوية، كل بطاقة عبارة عن بوابة لخدمة:

١. **الأداء التنفيذي**
- أيقونة Dashboard مع badge "محدّث".
- ملخص: آخر مؤشر تم تسجيله + نسبة الإنجاز الشهري.
- زر "افتح الأداء →".

٢. **بداية الأسبوع**
- أيقونة شروق الشمس.
- ملخص: عدد الرسائل المنتجة هذا الشهر + موضوع آخر رسالة.
- زر "ابدأ إنتاج محتوى →".

٣. **نهاية الأسبوع**
- أيقونة قمر.
- ملخص: آخر رسالة "نهاية أسبوع سعيدة" + تاريخها.
- زر "افتح الأرشيف →".

٤. **عام الذكاء الاصطناعي**
- أيقونة ذكاء اصطناعي.
- ملخص: إجمالي التفعيلات + آخر تفعيل مضاف.
- زر "افتح المعرض →".

البطاقات بخلفية بيضاء، حواف ناعمة، hover effect خفيف يرفع البطاقة قليلاً، وخط لوني علوي مميز لكل خدمة.

**ج) قسم "ملخص تنفيذي ذكي":**
بطاقة عريضة بعرض كامل تحتوي:
- عنوان: "ملخص الأسبوع التنفيذي".
- ٣–٤ نقاط مولّدة بالذكاء الاصطناعي تلخّص نشاط الإدارة هذا الأسبوع، تُحدّث تلقائياً كل صباح أحد عبر API call لـ Claude يحلّل البيانات من كل الجداول.
- زر "توليد ملخص جديد" يدوياً + زر "نسخ الملخص".
- توقيع: "تم التوليد في {التاريخ}".

**د) قسم مزدوج (عمودان):**

العمود الأيمن - "الأيام العالمية القادمة":
- قائمة بأقرب ٣ أيام عالمية خلال ٣٠ يوم القادمة.
- كل عنصر: اسم اليوم، التاريخ، عدّاد تنازلي "بعد X يوم"، زر "جهّز التفعيل".
- البيانات من جدول international_days.

العمود الأيسر - "آخر المبادرات":
- آخر ٥ مبادرات تمت إضافتها/تحديثها.
- كل عنصر: اسم المبادرة، التاريخ، حالتها (badge ملوّن).
- زر "عرض كل المبادرات →".

**هـ) قسم "نبض الأخبار العالمية":**
- شريط أفقي يعرض ٣ بطاقات أخبار مختصرة (عناوين فقط) من صفحة الأخبار العالمية.
- زر "افتح كل الأخبار ←".

**و) شريط أدوات سريعة (Quick Actions Bar):**
أزرار سريعة عائمة في أسفل المنطقة الرئيسية:
- ✨ إنتاج محتوى جديد
- 📅 إضافة يوم عالمي
- 📸 رفع تفعيل
- 🤖 المساعد الذكي
كل زر يفتح modal مباشر بدلاً من نقل المستخدم لصفحة كاملة.
